## Анализ interactiveAnalogLayout + LZ-роутер, имплементация улучшений
### Галочки настроек
- **Merge parallel edges** (`elk.layered.mergeEdges`): УБРАН из UI и кода.
  Анализ ELK bundle (elk-worker.js): `mergeEdges` работает только для edges
  без ports и НЕ side-fixed nodes. У нас ВСЕ nodes с `portConstraints: "FIXED_POS"`
  и ВСЕ edges с ports → опция архитектурно несовместима, никогда не работала.
- **Prefer straight edges** (`elk.layered.nodePlacement.favorStraightEdges`): СДЕЛАНА
  РАБОЧЕЙ. Раньше: передавалась только при `true` (а ELK при ORTHOGONAL сам
  ставит true по умолчанию → toggle был мёртвым). Теперь: всегда передаётся
  явно `String(opts.favorStraightEdges)` → `false` реально переопределяет
  auto-default. Default `true`. Проверено behaviorally через elkjs 0.11.1.

### LZ-роутер: edgeEdge + edgeNode
- Заменён хардкод `OBSTACLE_MARGIN=8` на `edgeNode ?? 12` (ELK default).
- Добавлен `WireGrid` — uniform-grid occupancy index для wire-wire spacing.
  Строится из сегментов ДРУГИХ нетов (кроме перерисовываемого). Cell size =
  edgeEdge; inflate to 8 neighbours. Штраф WIRE_PENALTY=20 за proximity.
- `routeNetLocal` теперь принимает `AnchorInfo[]` ({point, deviceKey}) и возвращает
  `edges: TracedEdge[]` — per-edge trace для surgical re-route.

### Surgical drag re-route (основная фича)
- `WireData` расширен: добавлен `edges?: TracedEdge[]` с fromKey/toKey.
- ELK result builder формирует `edges` с fromKey/toKey (из port ID → deviceKey).
- `rerouteNets` получил `mode: "surgical" | "full"` + `movedKeys: string[]`:
  - surgical (default): only edges touching moved devices re-routed; rest stay
    pixel-identical to ELK. Junctions recomputed via computeJunctions.
  - full: old hub-spoke behavior (routeNetLocal on all anchors).
- Переключение: `netlistDragMode` preference (default "surgical") + Shift во
  время drag = full (override на жест). NetlistSettingsPanel: кнопки Surgical/Full.
- Locked devices при загрузке: вместо full re-route всего нета → synthetic
  stub edge от locked anchor к nearest point на существующем trunk. ELK trunk
  сохраняется.
- Preferences: `netlistDragMode: "surgical" | "full"` (state, default, setter,
  partialize).
- Тесты: +11 (было 91 → 102). WireGrid (4), spacing options (3), edge trace (2),
  per-edge routeNetLocal trace (2).

## Фиксы: Shift+drag, wire spacing, status bar
- **Shift+drag**: убран early return на `e.shiftKey` в `onDevicePointerDown`.
  Shift+pointerdown теперь начинает drag (раньше — только toggle selection).
  Shift+click (без движения) обрабатывается в `endPointer` через `dragRef.shiftHeld`.
  Добавлено поле `shiftHeld` в dragRef.
- **Wire spacing**: WireGrid теперь строится инкрементально — после каждого
  перерисованного нета его сегменты добавляются в grid для последующих нетов.
  Раньше grid исключал ВСЕ re-routed неты → два нета в одном вызове могли
  наложиться друг на друга.
- **Status bar**: добавлен `liveDragMode` — при drag показывает
  "Surgical drag" / "Full re-route (Shift)" + подсказку "hold Shift to toggle".
  В статике показывает текущий режим из настроек.

## Фиксы: io pins, multi-terminal nets, hard grid spacing
- **Bug io pins**: port ID `io:123:Y:0` → `split(":")[0]` давал `"io"` вместо
  `"io:123"`. Добавлен `deviceKeyFromPort()` — корректно извлекает `io:123` и
  терминал `Y`. Без этого surgical drag не работал с Vin/Vout/VCC.
- **Bug multi-terminal nets** (PNP base/NPN collector в current mirror):
  `terminalOf` Map перезаписывал термины устройства на одном нете. Заменено
  на использование `fromTerminal`/`toTerminal` из `TracedEdge` (хранятся из
  ELK port id). Корректно для устройств с несколькими пинами на одном нете.
- **Fallback**: если surgical не может вычислить anchor (нет pin lookup и
  т.п.), нет перерисовывается в full mode.
- **Hard grid spacing**: координаты snap'ятся к сетке (кратно edgeEdge),
  WireGrid — hard constraint (collision → кандидат отклоняется). Если все
  кандидаты коллизируют — fallback на наименее плохой. Добавлены `collides()`,
  `snap()`, `countCollisions()`, `deviceKeyFromPort()`, поле `cellSize`
  сделано public readonly.

## Откат hard grid + фиксы: quick drag, export junctions
- **Hard grid ОТКАТЕН**: устройства двигаются свободно (не по сетке) — grid
  snapping ломал визуал. Возврат к penalty-based spacing. WIRE_PENALTY
  повышен с 20 до 200 для более строгого соблюдения зазора.
- **Quick drag bug**: endPointer отменял rAF без применения pending-позиции.
  Теперь перед cancelAnimationFrame вызывается applyDragPosition(pending) —
  провода всегда перерисовываются при отпускании ЛКМ.
- **Export junctions**: colorize-функция экспорта превращала fill="var(--ink2)"
  (точки узлов) в "none" — точки исчезали. Теперь var(--ink2) → #000000.
- **ELK parallel wires**: layered алгоритм рисует каждый (driver, consumer)
  как отдельный edge — для VDD rail это N отдельных polyline. mergeEdges
  мог бы слить, но не работает с FIXED_POS портами (проверено ранее).
  Это design алгоритма, не баг.

## Исправление multi-terminal power nets
- **Bug**: `portOf` в `elkInteractiveLayout` возвращал только ПЕРВЫЙ порт
  устройства на нете. Устройства с несколькими терминалами на GND (NMOS S+B,
  NPN E+B в current mirror) получали только один edge — остальные терминалы
  "висели в воздухе". Это также вызывало "первый drag = full" (surgical
  перерисовывал все имеющиеся рёбра, ломая шину).
- **Fix**: `NodePortSpec` получил поле `terminal`. `portOf` теперь ищет порт
  по комбинации (netId, terminal), а не только по netId. Все вызовы `portOf`
  передают имя терминала. Теперь GND net имеет ВСЕ рёбра для каждого терминала,
  surgical перерисовывает только инцидентные.
